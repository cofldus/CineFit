## 1. 지금 바로 만들 수 있는 가장 현실적인 MVP

**"서울·수도권 핵심 50관 × 현재 상영작, 수동 검증 데이터 기반의 설명형 추천 PWA"** (12주, 1~2인)

1. KOBIS/KMDb 자동 동기화로 영화 메타 확보, 기술 사양은 개봉 전 공식 발표를 관리자가 입력
2. 50관의 사양·좌석 존·접근성을 관리자 검수로 구축 (커뮤니티 정보는 제보 계층으로 분리 수용)
3. 회차는 핵심 관 주간 수동 입력 + 공식 예매 딥링크 (실시간 좌석 미수집)
4. 추천: 하드 필터 → 11축 점수 → 신뢰도·최신성 보정 → 균형/품질/가성비 3종 + 이유·단점·확신도
5. 배포 게이트: 골든셋 30케이스(Top3 ≥ 85%) + 사실성 자동 테스트 9종

## 2. 성공을 결정하는 가장 큰 데이터 문제 5개

1. **상영시간표 공급**: 합법 소스 부재. 수동 입력의 지속 가능성 한계 → KOFIC 개방·극장 제휴 성사 여부가 확장의 분수령.
2. **영화별 확장 화면비·믹스 확인의 적시성**: 개봉 전 공식 확인이 안 되는 작품이 다수 — "미확인" 상태로 추천 확신도를 낮추는 UX가 신뢰를 지킬 수 있는가.
3. **상영관 사양의 최신성 유지**: 리뉴얼·장비 교체를 놓치면 추천 전체가 오염(천호 CoLa 사례). 커뮤니티 속보→검수 파이프라인의 반응 속도가 관건.
4. **좌석 수준 데이터의 근거 확보**: 좌석별 시야·음향은 실측 불가 — 제보 축적 전까지 '추정' 라벨 운영과 초기 콜드스타트.
5. **극장 산업 변동성**: 메가박스 회생절차 등으로 지점·특별관 존폐 자체가 유동적 — 운영 상태 추적이 상시 업무가 됨.

## 3. 개발 시작 전에 사람이 직접 결정해야 할 사항 5개

1. **법무 확정**: KOBIS 약관 전문·쿼터, TMDB 상업 라이선스 필요 여부, 롯데시네마 약관 해석 — 변호사 검토 여부.
2. **CineFit 상표·도메인**: 국내외 상표 검색·출원, 도메인 확보 (이번 조사에서 미실시).
3. **콘텐츠 운영 인력**: 50관 검증·주간 회차 입력·제보 검수에 주 몇 시간을 투입할 수 있는가 — MVP 범위(50 vs 100관)가 여기에 종속.
4. **골든셋 전문가 섭외**: 추천 정답 순위를 매길 특별관 경험자 2인 이상 — 커뮤니티 협업 방식 포함.
5. **KOFIC·극장 제휴 접촉 시점과 주체**: 알파 전 접촉(트래픽 실적 없이) vs 베타 후 접촉(지표 들고) 전략 선택.
