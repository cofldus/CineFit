## 3. 사용자가 겪는 문제 (근거 연결)

1. **같은 브랜드, 다른 설비**: 천호 IMAX는 GT 비율 스크린이지만 CoLa 영사기 — 브랜드명만으로 판단 불가 (근거: 커뮤니티 리뉴얼 후기, `사용자 제보`).
2. **온전한 버전의 희소성**: The Odyssey(2026-07-17 개봉)의 IMAX 70mm 완전판은 미국 25개관 한정, 매진 사태 — CNBC·Fortune·Axios 보도로 주류화 (`공식 확인` 수준 보도).
3. **정보 노후화**: 대표 정리글(익스트림무비 11151669, 35328239)은 최종 수정 2021-12/2020-07 — 이후 왕십리·천호 리뉴얼, 코엑스 개편 미반영 (`오래된 정보`의 전형).
4. **주관·개인차**: 정리글 작성자 스스로 "개인차가 있을 수 있다" 명시. 좌석 명당도 목적(몰입/자막/사운드)마다 다름.
5. **접근성 정보의 분산**: 가치봄(배리어프리) 상영 일정이 협회 게시판·월별 게시글로 분산 — 3사 앱 내 통합 필터 존재 여부 확인되지 않음.

## 4. 기존 커뮤니티 자료의 가치와 한계

- **가치**: 실측 수준의 스펙 정리(크기·마스킹·밝기), 목적별 명당표(예: 코돌비 H열 명당·D열 목아픔), 리뉴얼·장비 변경의 최속 전파(천호 CoLa 확정을 커뮤니티가 먼저 특정).
- **한계**: 측정 방법 미제시, 노후화, 약칭·평판의 관성(리뉴얼 후에도 옛 평가 유지), 출처 간 충돌(돌비 크기 순위).
- **결론**: 커뮤니티 데이터는 `사용자 제보` 계층으로 수용하되 공식 사양과 분리 저장하고, 최신성·복수 일치도로 가중하는 구조가 필수 (→ 문서 6, 10).

## 5. 데이터 확보 가능성

### 5.1 확보 가능 (합법·무료)
- **KOBIS 오픈API**: 박스오피스, 영화목록/상세(등급·개봉일·상영타입·감독·배급사). REST XML/JSON. 쿼터는 서드파티 기준 키당 일 3,000회(공식 수치 미확인) — `단일 출처 미확인`.
- **KMDb API**(한국영상자료원): 한국영화 메타데이터, 공공데이터포털 등재.
- **TMDB**: 포스터·해외작 메타데이터. 비상업 무료+출처표기, 상업화 시 월 $149~ — `공식 확인`.
- **LF Examiner 아카이브**: 2025-03부터 CC BY-NC-SA 4.0 공개(대형포맷 극장 DB 포함) — NC 조건이라 상업 서비스 직접 사용 불가, 검수용 참고 자료로만.
- **지도·이동시간**: 카카오(내비 일 1만 건 무료), TMAP(대중교통 GTFS 기반), 네이버(다이내믹맵 무료 확대), 구글(SKU당 월 1만 회 무료) — 세부 단가 일부 확인되지 않음.

### 5.2 확보 곤란 (핵심 병목)
- **극장별 상영시간표**: KOBIS 웹사이트에 조회 화면은 존재하나 API 미개방. 3사 공개 API 없음. CGV robots.txt는 AI·봇 다수 명시 차단(ClaudeBot, GPTBot 등 Disallow), 메가박스는 robots.txt 접근 자체 차단, 롯데시네마는 형식상 전체 허용(단 약관 별개).
- **실시간 좌석 잔여**: 예매 시스템 내부 데이터. 무단 수집은 기술적·법적 고위험. → 공식 예매 딥링크 + 사용자 확인 구조로 우회 (MVP 전제).

### 5.3 법적 위험 (판례)
- 여기어때 vs 야놀자(대법 2022-05-12): 공개 정보 크롤링 **형사 무죄** 확정.
- 잡코리아 vs 사람인: **DB권 침해 민사 인정**, 총 4.5억 원 배상. robots.txt 미확인·UA 미표시·IP 분산이 위법성 판단에 반영.
- 시사점: 상영시간표는 각 사의 투자로 구축된 DB → DB권 주장 여지. **저빈도·UA 명시·robots 준수**가 최소 방어선이며, 명시 차단 사이트 우회는 하지 않는다.

## 7. 법적·운영 위험 종합

1. 상영시간표 무단 수집 → DB권 민사 리스크 (§5.3)
2. 포스터·스틸 이미지 저작권 → TMDB 라이선스 범위 또는 KOBIS/KMDb 제공 자료 확인 필요, MVP는 포스터 없이 성립하는 UI(문서 9)
3. 커뮤니티 후기 원문 대량 복제 → 저작권 침해. 사실 정보만 구조화 + 원문 링크
4. 메가박스 기업회생(2026-06-14 신청, `공식 확인`) → 지점 폐점 시 데이터 무효화 대량 발생 가능. 상영관 상태(운영/휴업/폐점) 필드와 이력 모델 필수
5. 약칭 상표 문제: "용아맥" 등은 커뮤니티 관용어 — 검색 별칭으로만 사용, 공식 명칭과 분리 표기

## 8. 확인된 사실 vs 가정

- **사실(공식/복수 출처)**: §2 표의 상태 표기 참조.
- **가정(추정·분석, 설계 진행용)**:
  - A1. 상영시간표는 MVP 기간 중 제휴 확보 불가 → 관리자 수동 입력 + 공식 페이지 딥링크로 대체 가능하다.
  - A2. 서울·수도권 특별관 50~100개의 스펙·좌석 정보는 관리자 수동 검증으로 6~8주 내 구축 가능하다.
  - A3. 영화 기술 사양(신작)은 개봉 2~4주 전 공식 발표·매체 가이드에서 수동 수집 가능하다.
  - A4. 커뮤니티 제보 기반 데이터는 사용자 20~50명 알파 단계에서 검증 가능하다.
