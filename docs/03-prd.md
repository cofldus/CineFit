# 문서 3. PRD (Product Requirements Document)

- 조사 기준일: 2026-07-27 | 서비스: CineFit(시네핏)

## 1. 목표

1. 사용자가 영화 하나를 정한 뒤 **3분 이내**에 "어느 극장, 어느 회차, 어느 좌석"을 결정할 수 있다.
2. 모든 추천에 이유·단점·데이터 신뢰도·마지막 확인일이 표시된다.
3. 확인되지 않은 정보를 사실처럼 표시하지 않는다 (사실성 요구사항, 문서 11 §2).

## 3. 기능 요구사항

### FR-1 영화
- 검색(제목·원제·별칭·오탈자 허용), 상세(기본 정보 + 기술 사양 + 개봉 상태 8단계).
- 기술 사양은 항목별 정보 상태 배지 필수. 개봉 전 작품에 "관람평" 영역 미노출(시사회 반응은 별도 라벨).

### FR-2 상영관
- 개별 관 단위 페이지(체인-지점-관 번호). 사양·좌석도·목적별 명당·최근 변경·제보 이력.
- 별칭(용아맥 등) 검색 매핑. 운영 상태(운영/휴업/폐점/리뉴얼 중) 표시.

### FR-3 회차
- 회차 = 영화×관×일시×포맷×언어. "관에 IMAX가 있음"과 "이 회차가 IMAX 버전"을 분리.
- MVP: 관리자 수동 입력 + 공식 예매 딥링크. 좌석 잔여는 수집하지 않고 사용자가 예매 페이지에서 확인.

### FR-4 추천
- 빠른 추천(입력 5개) / 고급 설정(문서 5 §2). 결과는 최소 3개 + 부가 답변(특별관 불필요 사유, IMAX vs Dolby, N차 조합, 대기 vs 예매).
- 모든 결과에 이유·단점·확신도·확인일. 하드 조건은 점수로 상쇄 금지.

### FR-5 좌석
- 좌석도 열람 + 목적별 추천(몰입/조망/자막/사운드/멀미완화/목편함/출입/2인/휠체어).
- 좌석별 시야각·체감 크기 근사치는 "추정" 라벨로 구분.

### FR-6 제보·검수
- 사실형 제보(사양 변경·고장·좌석)와 주관형 평가(세분화된 축) 분리 입력.
- 중복 병합, 최신 가중, 신고, 관리자 승인 워크플로.

### FR-7 검색
- 한국어 자연어 질의("용아맥이랑 남돌비 중 어디가 좋아?") → 엔티티+조건 추출 → 구조화 검색.
- LLM은 설명 생성만, 사실은 DB 근거(문서 5 §8).

## 4. 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 성능 | 추천 응답 p95 < 2s(후보 ≤ 200회차), 검색 p95 < 500ms |
| 가용성 | 베타 99.5%. 수집 실패가 사용자 조회를 막지 않음(캐시 우선) |
| 접근성 | WCAG 2.1 AA. 색 단독 구분 금지, 스크린리더 대응 |
| 개인정보 | 위치는 단말 처리 또는 구·시 단위 축소 저장. EXIF 제거. 계정 삭제·데이터 다운로드 제공 |
| 사실성 | 미확인 정보 표기 의무. 사실성 테스트(문서 11 §2) 통과가 배포 게이트 |
| 법규 | robots.txt·약관 준수, 명시 차단 소스 미수집 |

## 5. MVP 범위 / 제외 범위

**포함**: 서울·수도권 특별관+우수 일반관 50~100관, 현재 상영작+개봉 예정 주요작, 기능 FR-1~7의 수동 데이터 기반 버전, PWA 웹.
**제외(후속)**: 실시간 좌석 자동 수집, 전국 커버, 소셜 기능, 네이티브 앱, 자동 상영시간표 수집(제휴 전), 해외 극장.

## 6. 예외 상황 처리 (문서 1 §9 사각지대 대응)

- 리뉴얼 감지 시: 과거 사양·리뷰 자동 분리(`valid_to` 마감), 신 사양은 "확인 필요" 상태로 시작.
- 출처 충돌 시: 양쪽 값 병기 + "출처 충돌" 배지, 추천 확신도 하향.
- 데이터 없음 시: 추천에서 "정보 부족" 명시, 해당 축 점수는 중립값 + DataConfidence 감점.
- 폐점·회생절차 등 운영 불확실: 상영관 상태 필드로 노출 제어, 추천 후보 제외.

## 7. 승인 기준 (MVP 출시 게이트)

1. 골든 데이터셋 30케이스에서 전문가 Top1 일치율 ≥ 60%, Top3 포함률 ≥ 85% (문서 11 §1).
2. 사실성 자동 테스트 9종 전체 통과 (문서 11 §2).
3. 핵심 50관 데이터 100% 관리자 검증 완료, 30일 내 확인 비율 ≥ 80%.
4. 접근성 자동 검사(axe) 심각 위반 0건, 수동 스크린리더 시나리오 3종 통과.
5. 알파 사용자 20명 인터뷰에서 "추천 이유를 이해했다" ≥ 80%.
