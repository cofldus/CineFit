# 문서 9. UX/UI 설계

- 조사 기준일: 2026-07-27 | 서비스: CineFit(시네핏) | 패키지: `@cinefit/ui`

## 1. 디자인 원칙

1. **결정 속도 우선**: 화려한 영화 앱이 아니라 3분 내 결정을 돕는 정보 계층. 결론 먼저, 근거는 펼침.
2. **신뢰가 보이는 UI**: 모든 사양 옆에 상태 배지(공식/복수출처/제보/오래됨/충돌/확인필요)와 확인일.
3. **용어 번역**: 전문 용어 첫 등장 시 ⓘ 팝오버로 쉬운 설명("1.43:1 = 거의 정사각형에 가까운 큰 화면").
4. **손해도 보여주기**: 추천 카드에 장점과 같은 비중으로 단점·포기 항목 표기.
5. **포스터 독립**: 저작권 미확보 전제 — 텍스트·아이콘·포맷 그래픽만으로 성립하는 카드.
6. **중립성**: 제휴·광고는 "AD" 라벨+분리 블록. 순위 영역 침범 금지.


## 3. 핵심 컴포넌트

| 컴포넌트 | 규격 |
|---|---|
| TrustBadge | 상태 8종. 색+아이콘+텍스트 병기(색 단독 구분 금지) |
| FormatTag | IMAX/Dolby Cinema/4DX/SCREENX/일반 등 — 브랜드 로고 대신 텍스트 태그 |
| RecommendCard | 순위 라벨(균형/품질/가성비)·결론 1줄·핵심 수치 행(거리·시간·가격)·이유 2·단점 1·확신도·확인일·[좌석 보기][예매] |
| CompareTable | 최대 3회차 × 10축, 가로 스크롤 컨테이너 |
| SeatMapViewer | 존 하이라이트(목적 칩 선택), 좌석 탭 → 하단 시트(체감크기·시야각·주의점, '추정' 라벨) |
| SpecRow | 사양 항목명 + 값 + TrustBadge + 출처 링크 + 확인일 |
| EmptyState/ErrorState/Skeleton | 모든 목록·상세 화면에 3종 상태 필수 |

## 4. 화면별 명세 (14화면 — 프로토타입 대응)

1. **온보딩**: 가치 1문장("영화에 딱 맞는 상영관을 찾아드려요") → 위치 권한(거부 시 지역 직접 선택) → 취향 3문항(건너뛰기 상시 노출) → 최소 수집 안내.
2. **홈**: 검색바("어디서 보면 좋을까요?") / 현재 상영작 가로 리스트 / 오늘 예매 가능한 추천 / 저장작.
3. **영화 검색**: 자연어+자동완성(영화·극장·약칭 엔티티 구분 아이콘), 최근 검색.
4. **영화 상세**: 상태 칩(국내 개봉 등 8단계) / 기술 사양 SpecRow 목록 / "이 영화에 맞는 관람 방식" / [추천 받기]. 개봉 전 작품은 관람평 영역 자체가 없음(시사회 반응만 별도 라벨).
5. **빠른 추천 조건**: 5입력 1스크린(위치·날짜시간·거리·중요도 칩 9개 중 1) + "고급 설정" 링크.
6. **추천 결과**: RecommendCard 3장 + 부가답변 아코디언("이 영화엔 특별관이 굳이 필요 없어요" 등) + 지도 토글.
7. **비교 화면**: CompareTable(화면/화질/사운드/체험/좌석/이동/가격/종료/접근성/신뢰도).
8. **상영관 상세**: 관 사양·이력 타임라인·최근 제보·영화별 적합도·[수정 요청].
9. **좌석 추천**: SeatMapViewer + 목적 칩.
10. **예매 전 최종 확인**: 선택 요약(회차·좌석 목적·가격·종료 시각·귀가 교통 주의) + "공식 예매 페이지로 이동합니다. 좌석·가격은 예매 페이지 기준" 고지 + 딥링크.
11. **정보 출처**: 해당 추천에 사용된 출처·확인일·상태 전체 목록.
12. **오류 제보**: 유형 선택(사실형/주관형) → 구조화 폼 → 사진(EXIF 제거 안내).
13. **마이페이지**: 취향·민감도·접근성 설정, 학습된 취향 열람·초기화, 저장·제보 이력, 계정 삭제/데이터 다운로드.
14. **관리자 검수**: 큐(신규 제보/충돌/노후/파서 실패/리뉴얼 의심) + 극장별 완성도 히트맵.

## 5. 접근성

- WCAG 2.1 AA: 명암비 4.5:1(토큰 검증), 포커스 링, 스크린리더 레이블(배지·점수의 텍스트 대체),
  키보드 탐색(비교 테이블 포함), 애니메이션 감소 설정 존중(`prefers-reduced-motion`).
- 색 단독 의미 금지: TrustBadge·좌석 존은 패턴/아이콘 병기.
- 좌석도: 스크린리더용 텍스트 요약("휠체어석은 K열 좌측, 입구에서 평지 접근") 제공.
- 잘못된 추천 신고: 모든 추천 카드 오버플로 메뉴에 "이 추천이 이상해요" 1탭 진입.
