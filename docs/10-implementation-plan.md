## 2. 마일스톤 (주 단위, 1~2인 개발 가정)

- **M1 (1~2주)**: E1+E2 완료. DoD: 마이그레이션·시드 CI 통과, observations 승격 흐름 단위 테스트.
- **M2 (3~5주)**: E3+E4. DoD: KOBIS 일배치 안정 3일, 관리자 콘솔로 관 1개 완전 입력 가능.
- **M3 (4~8주, 병행)**: E5 콘텐츠 — 주 15관 페이스로 50관 검증 입력. DoD: 50관 100% + 신선도 표기.
- **M4 (5~8주)**: E6+E11. DoD: 골든셋 30케이스 Top3 ≥ 85%, 사실성 테스트 9종 통과.
- **M5 (7~10주)**: E7+E9+E10. DoD: 빠른 추천 E2E(입력→카드→딥링크) p95 < 2s.
- **M6 (10~12주)**: E8+E12, 알파 배포. DoD: 알파 사용자 20명 온보딩, 피드백 루프 가동.

## 3. 대표 작업 분해 예 (E6 추천 엔진)

1. 특징량 추출기(영화 사양→FilmFormatMatch 입력) — 사양 결측·미확인 케이스 테이블 주도 테스트
2. 하드 필터 모듈 (접근성·민감도 케이스 스냅샷 테스트)
3. 11축 스코어러 + 프리셋 가중치
4. Trust/Freshness 보정기 (반감기 파라미터화)
5. 다양성 셀렉터(균형/품질/근접)
6. 설명 생성기(특징량→reason/tradeoff/uncertain, observation 인용 강제)
7. 평가 러너(골든셋 NDCG 리포트를 CI 아티팩트로)

## 4. 완료 조건(전 에픽 공통 DoD)

- 타입 안전(TS strict), 단위 테스트 포함, 오류 처리(사용자 노출 문구 포함), 접근성 체크(해당 시),
  사실성 규칙 위반 없음(미확인 정보 표기), 코드리뷰 1인 이상.

## 5. 기술 부채 방지 기준

- 파서/수집 코드는 픽스처 없는 머지 금지.
- "임시 하드코딩 사양 데이터" 금지 — 모든 사양은 observation 경유(시드도 동일 경로).
- 추천 로직 변경 시 골든셋 회귀 리포트 첨부 의무.
- 스키마 변경은 마이그레이션+롤백 스크립트 쌍으로만.
