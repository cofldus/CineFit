# 문서 12. 출시 계획

- 조사 기준일: 2026-07-27 | 서비스: CineFit(시네핏)

## 0단계 — 조사·검증 (완료/진행)
- 데이터 출처·법적 검토: 문서 1·7 완료. 잔여: KOBIS 약관 전문·쿼터 공식 확인, KOFIC 상영스케줄 개방 문의 발송, TMDB 상업 라이선스 판단.
- 핵심 상영관 후보 목록 확정(50관: 수도권 IMAX 전 지점, Dolby Cinema 수도권, ULTRA 4DX/SCREENX 대표관, SUPER PLEX 월드타워 외, 우수 일반관, 독립·예술관 5곳).
- 추천 규칙 초안: 문서 5. 골든셋 30케이스 작성(전문가=특별관 커뮤니티 경험자 2인 섭외 권장).

## 1단계 — 내부 프로토타입 (2주)
- Figma 프로토타입(14화면)으로 추천 설명·신뢰 배지 이해도 테스트(5인 게릴라).
- 더미 데이터로 정보 계층 검증. 실패 기준: 카드에서 "왜 이 추천인지" 10초 내 파악 불가 시 재설계.

## 2단계 — 비공개 알파 (M6 이후, 4~6주)
- 대상: 영화 마니아 20~50명(익스트림무비·무코 등에서 모집 — 데이터 제보자 겸임).
- 범위: 서울 핵심 50관, 수동 데이터. 주간 데이터 확인 루틴(관리자 SLA: 회차 오류 24h 내 수정).
- 산출: 추천 인터뷰, 골든셋 확장, 제보 품질 파악.

## 3단계 — 공개 베타 (PWA)
- 수도권 100관 확대, 사용자 제보·오류 신고 오픈, 품질 대시보드 공개(신선도 %를 서비스 신뢰 마케팅으로).
- 지표: 문서 2 §5 베타 목표. 주간 릴리스, 기능 플래그로 점진 공개.

## 4단계 — 모바일 앱
- React Native(`@cinefit/mobile`), 위치·푸시(좋은 좌석·가격 알림)·딥링크. 스토어 심사 대비 개인정보 처리방침 정비.

## 5단계 — 제휴·확장
- 극장 공식 데이터 제휴(성사 시 파서→피드 전환), 배급사 기술 사양 공식 제공 채널, 전국 확대, 해외(일본·미국 IMAX/Dolby) 검토.

## 운영 체계

- **CI/CD**: GitHub Actions — lint/test/사실성 게이트/골든셋 회귀 → Vercel/컨테이너 배포. main 보호, PR 필수.
- **DB**: 마이그레이션 dry-run 게이트, 일일 스냅샷 백업+PITR, 복구 리허설 분기 1회.
- **롤백**: 웹은 이전 배포 즉시 전환, DB는 롤백 마이그레이션. 데이터 오염 시 observations 불변 로그에서 대표값 재산출.
- **장애 대응**: 심각도 정의(S1: 추천 전체 오류/개인정보, S2: 특정 소스 오염, S3: 단건 오류).
  S1 즉시 배너+기능 차단, S2 해당 소스 격리(source 단위 비활성), 포스트모템 48h.
- **데이터 수정 SLA**: 사실 오류 신고 → 확인 24h, 수정 72h 내. 극장 관계자 공식 요청 → 우선 처리 + 검증 배지.
- **운영 매뉴얼**: 주간 신선도 점검, 회차 입력 체크리스트, 충돌 판정 가이드(문서 6 §4), 제보 검수 기준, 리뉴얼 이벤트 처리 절차(사양 세대 분리→리뷰 격리→재검증).
