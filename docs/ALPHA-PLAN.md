# 알파 테스트 계획 — 현재 상태와 이번 Phase 범위

- 기준일: 2026-07-28 (7차 마일스톤)

## 착수 전 검증 결과 (실제 상태 — 문서상 기대와 다름)

Phase 7 착수 지시서는 "공개 베타가 이미 배포돼 있고 실제 사용자를 알파에 초대한다"를
전제로 한다. 검증 결과 **그 전제는 사실이 아니다**:

| 확인 항목 | 실제 상태 |
|---|---|
| `git log`/`git status` | `main`이 origin과 완전히 동기화. 직전까지의 이력은 5차 마일스톤(UI 리디자인)까지만 존재 — "Phase 6" 배포 작업 자체가 없었다 |
| 배포 설정 | Vercel/Railway/Fly/Render 등 어떤 호스팅 설정 파일도 저장소에 없음. `.github/workflows/`에 배포 job 없음(`ci.yml`은 테스트 게이트만) |
| production DB | `.env`에 `DATABASE_URL`·`CINEFIT_ENV`·`ADMIN_PASSWORD` 전부 비어 있음 — 앱이 `CINEFIT_ENV=production`으로 실행된 적이 없다 |
| 공개 베타 URL | 없음 |
| 실제 사용자 수 | 0명 |

**결론**: 이번 Phase에서 "실제 사용자 20~50명 알파 테스트"를 문자 그대로 수행할 수 없다.
배포·모집·실사용자 인터뷰는 사용자가 직접 결정하고 진행할 인프라·비용·개인정보 관련
사안이라 자동으로 진행하지 않는다(사용자 확인 완료, 2026-07-28).

## 이번 Phase의 실제 범위

**진행**: 알파 테스트를 실제로 시작할 때 곧바로 쓸 수 있는 코드 인프라를 미리 만든다.

- 익명 분석 이벤트 파이프라인(개인정보 최소화)
- 추천 즉시 피드백 + 실제 선택 기록
- 관람 후 만족도 흐름
- 추천 정책 버전 관리 + 실행 기록 확장
- 골든 추천 데이터셋 + 오프라인 평가 CLI
- 추천 실패 원인 분류
- 상영관 데이터 완성도·최신성 + 관리자 품질 대시보드
- 예매 링크 검증 + 유지보수 CLI
- 영화·상영관 검색(별칭 포함)
- 경량 온보딩(3문항, 건너뛰기 가능)
- 기능 플래그(관리자 전용)
- 위 기능에 대한 테스트

**보류** (사용자 결정 필요 — 이번 Phase에서 다루지 않음):

- 실제 배포(호스팅·도메인·Postgres 프로비저닝)
- 알파 테스터 모집·초대 코드 발급·실제 참여자 관리
- 실제 사용자 인터뷰(5~10명)
- A/B 테스트(충분한 표본·고지 정책이 준비되기 전까지 금지 — 지시서 §17과 동일 원칙)

## 알파 시작 전 사람이 해야 할 일 (이번 Phase가 끝나도 남는 작업)

1. 호스팅 결정(Vercel/Railway/Fly 등) + 도메인
2. PostgreSQL 프로비저닝(Supabase 등, `.env.example`에 이미 pooled 연결 안내 있음) 후
   `CINEFIT_ENV=production` + `DATABASE_URL` 설정
3. `ADMIN_PASSWORD` 운영값 설정, 백업 정책 수립
4. 알파 테스터 모집 채널 결정(초대 코드/비공개 URL 중 택1 — 이번 Phase는 두 방식 모두
   구현만 해두고 실제 발급·홍보는 하지 않는다)
5. 실제 사용자 인터뷰 진행(가이드는 이번 Phase에서 작성)
6. KOBIS 상업적 사용 범위 KOFIC 서면 확인(4차 마일스톤부터 이어지는 미해결 항목)
7. KMDb API 키 승인 대기(계속 보류)
