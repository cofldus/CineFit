# 알파 테스트 계획 — 현재 상태와 이번 Phase 범위

- 기준일: 2026-07-28 (7차 마일스톤)

## 착수 전 검증 결과 (실제 상태 — 문서상 기대와 다름)

Phase 7 착수 지시서는 "공개 베타가 이미 배포돼 있고 실제 사용자를 알파에 초대한다"를
전제로 한다. 검증 결과 **그 전제는 사실이 아니다**:

| 확인 항목 | 실제 상태 |
|---|---|
| `git log`/`git status` | `main`이 origin과 완전히 동기화. 직전까지의 이력은 5차 마일스톤(UI 리디자인)까지만 존재 — "Phase 6" 배포 작업 자체가 없었다 |
| 배포 설정 | Vercel/Railway/Fly/Render 등 어떤 호스팅 설정 파일도 저장소에 없음. `.github/workflows/`에 배포 job 없음(`ci.yml`은 테스트 게이트만) |
| production DB | `.env`에 `DATABASE_URL`·`CINEFIT_ENV`·`ADMIN_PASSWORD` 전부 비어 있음 — 앱이 `CINEFIT_ENV=production`으로 실행된 적이 없다 |
| 공개 베타 URL | 없음 |
| 실제 사용자 수 | 0명 |

**결론**: 이번 Phase에서 "실제 사용자 20~50명 알파 테스트"를 문자 그대로 수행할 수 없다.
배포·모집·실사용자 인터뷰는 사용자가 직접 결정하고 진행할 인프라·비용·개인정보 관련
사안이라 자동으로 진행하지 않는다(사용자 확인 완료, 2026-07-28).

## 이번 Phase의 실제 범위

**진행**: 알파 테스트를 실제로 시작할 때 곧바로 쓸 수 있는 코드 인프라를 미리 만든다.

- 익명 분석 이벤트 파이프라인(개인정보 최소화)
- 추천 즉시 피드백 + 실제 선택 기록
- 관람 후 만족도 흐름
- 추천 정책 버전 관리 + 실행 기록 확장
- 골든 추천 데이터셋 + 오프라인 평가 CLI
- 추천 실패 원인 분류
- 상영관 데이터 완성도·최신성 + 관리자 품질 대시보드
- 예매 링크 검증 + 유지보수 CLI
- 영화·상영관 검색(별칭 포함)
- 경량 온보딩(3문항, 건너뛰기 가능)
- 기능 플래그(관리자 전용)
- 위 기능에 대한 테스트

**보류** (사용자 결정 필요 — 이번 Phase에서 다루지 않음):

- 실제 배포(호스팅·도메인·Postgres 프로비저닝)
- 알파 테스터 모집·초대 코드 발급·실제 참여자 관리
- 실제 사용자 인터뷰(5~10명)
- A/B 테스트(충분한 표본·고지 정책이 준비되기 전까지 금지 — 지시서 §17과 동일 원칙)

### 트랙별 요약

1. **사전 검증 + CI 실환경 정합성**(`docs/TESTING.md` §6): CI가 e2e job 도입 이후 계속
   조용히 실패하고 있었던 실제 버그(리눅스 베이스라인 생성 컨테이너와 CI 러너 환경 불일치)를
   발견·수정. `beb1bac`.
2. **호스팅 결정**(ADR-6, `docs/08-architecture.md`): Vercel(앱) + Supabase(PostgreSQL
   호스팅만, BaaS 클라이언트 미사용) 채택. `47eb881`.
3. **PostgreSQL 하드닝**: pg Pool 안전장치(연결·유휴·statement 타임아웃), graceful shutdown.
   `47eb881`.
4. **SQLite→PostgreSQL 이전 검증**: `feature_flags`·별칭 테이블까지 포함한 이전 도구를
   dry-run/실행/멱등성/롤백 4가지로 검증하며, 진짜 커넥션 풀 누수 버그를 발견해 수정.
   `1b6d558`.
5. **KMDb 어댑터**: KOBIS 어댑터와 동일한 구조(unchanged-hash 감지, dry-run, 트랜잭션
   승격)로 구현. 스키마 검증 허점(임의 JSON이 전부 통과하던 버그)을 네거티브 테스트로
   발견·수정. `6f6c809`.
6. **KOBIS↔KMDb 식별자 연결**: 순수 함수 매칭기(제목·감독·연도 신호) + 등급 체계
   (exact/high_confidence/needs_review/conflict/unmatched) + 관리자 검토 화면. 동점
   후보는 자동 연결하지 않고 사람이 고르게 설계. `3536741`.
7. **골든셋 편향 감사 + 독립 holdout + 적대적 평가**: 51개 시나리오의 실제 편향 통계를
   숨기지 않고 그대로 기록(우선순위 88.2%가 'priority', 출발지 90.2%가 'cityhall' 등),
   같은 방법론으로 만든 독립 holdout 33개, 고정 기대값 대신 불변식을 검증하는 적대적
   평가 13개 추가. `ba62c08`.
8. **비공개 알파 게이트**: 초대 코드 + 참여 동의, 기본 꺼짐(`private_alpha_gate`),
   DB 조회 실패 시 fail-open. 진단에 여러 단계가 걸린 실제 버그(클라이언트 라우터 캐시가
   동의 전 리다이렉트를 재사용) 발견·수정, 같은 유형의 `e.currentTarget`-after-`await`
   버그를 두 컴포넌트(하나는 이번 마일스톤 것, 하나는 7차 마일스톤부터 있던 것)에서 발견·수정.
   `79ef9c3`.
9. **데이터 보존·삭제 요청**: 나이 기준 자동 정리(`retention:preview`/`:apply`) + 세션
   자기확인 기반 삭제 요청 + 이메일 기반 제보 연락처 삭제 요청, 관리자 검토·감사 로그.
   `35fd797`.
10. **관측성 + 알파 운영 대시보드**: 구조화 로깅(`src/lib/logger.ts`), `/admin/alpha-ops`

11. **CI 감사**: 새 fixture 테스트 전부가 기존 와일드카드 패턴으로 이미 자동 게이트되고
    있음을 확인, 유일한 실제 공백(KMDb 실호출 수동 점검 워크플로 부재)을 발견해 KOBIS와
    대칭으로 추가. `6dfd1f7`.
12. **배포 준비 + 체크리스트**: 헬스 체크(`/api/health`), Vercel Cron 라우트 3개

    `docs/DEPLOYMENT.md`. 문서를 쓰며 실제 로컬 PostgreSQL에 명령을 직접 실행해 검증하다
