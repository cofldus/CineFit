# Design Lab — 5개 홈 시안 비교 (2026-07-30)

브랜치: `design-lab/art-directions` (main 기준, 운영 홈 미변경, 병합 안 함)
경로: `/design-lab/a`, `/design-lab/b`, `/design-lab/c`, `/design-lab/d`, `/design-lab/e` — 하드코딩 데모 데이터, 실제 API 미연결.
스크린샷: `design/design-lab/{a,b,c,d,e}/home-{390,768,1440}.png`

이전 두 라운드(phase10/home-visual-reset)는 "정돈된 제품 랜딩" 구조(좌우 분리 Hero, 카드
3개, 01~04 리스트, 신뢰도 불릿+CTA)를 그대로 둔 채 배경 그리드·화면비 숫자·블루 광원만
더했다는 지적을 받았다. A/B/C 세 시안은 그 구조 자체를 서로 다르게 다시 짰다. 이후
A/B/C에 대한 피드백("다 별론데... 더 세련되고 단단한 멋쟁이 극장 느낌, 깔끔하고
현대적이면서 빨간색/크림슨 포인트, 따뜻하되 아늑하고 널찍한 느낌")을 반영해 D를 추가
제작했고, D에 대해서도 "영화 극장 스크린 생각나게, CGV 느낌"이라는 피드백을 받아 E를
추가 제작했다.

## 시안 간 차이 검증

| 항목 | A. Archive | B. Collage | C. Curator's Desk | D. Grand Foyer | E. The Screening Room |
|---|---|---|---|---|---|
| Hero DOM | 텍스트만, 단어별 `<span>` 분리·가장자리 확장 | 겹치는 절대배치 레이어(제목·프리뷰 카드·CTA) | 문장+각주+인라인 링크, 비주얼 오브젝트 없음 | 중앙 정렬, 크림슨 이중 룰이 감싼 마퀴 사인보드 문구 | 문구는 객석(다크)에, 그 아래 실제로 빛나는 스크린 오브젝트 + 좌석 실루엣 |
| 영화 영역 | `<ol>` 편집 지면 3종(좌우 반전·막대 그래프 등 서로 다른 내부 그리드) | 실제 화면비로 만든 콜라주 패널 3종(레터박스/플래시/크롭 슬리버) | 번호 붙은 메모 리스트, 밑줄 스펙 태그 | 카드 아닌 단일 사인보드 프레임 안에 3행(첫 행만 확대) | 1관·2관·3관 "상영관 문" 3개, 문틈으로 새어 나오는 빛의 양이 서로 다름(86/60/34%) |
| 배경 리듬 | 흰 배경 고정, 톤 변화 없음 | 다크 배경 하나로 처음부터 끝까지 연속(색 섹션 전환 없음) | 웜페이퍼 배경 고정, 톤 변화 없음 | 다크→라이트→다크 정확히 한 번(반복 아님, 대칭 bookend) | 다크 배경 하나로 연속(B와 달리 스크린 자체의 빛만 유일한 광원) |
| 카드 개수 | 0 (카드 자체가 없음) | 0 (콜라주 패널, 테두리 카드 아님) | 0 (메모 리스트 + 노트카드 1개) | 0 (사인보드 1개 안에 3행) | 0 ("문" 3개, 각각 독립된 그래픽 오브젝트) |
| 타이포 활용 | 초대형 슬랩 타이포 + 모노스페이스 타임코드 | 겹치는 레이어드 타이포, 자간 타이트 | 중간 크기 헤드라인 + 손글씨 밑줄 + 세리프(Lora) 메타 | 중간 크기 헤드라인, 좌우 대칭·중앙 정렬 전용 | 중간 크기 헤드라인 중 한 단어만 레드 강조, 나머지는 B/D보다 절제 |
| 액센트 | 코발트 블루 1개 | 일렉트릭 블루 1개(그레이디언트 아님, 텍스트·글로우 전용) | 적색 1개(에디팅 마크) | 크림슨 1개(룰·버튼·구분 눈금 전용) | 시네마 레드 1개(뱃지·버튼 전용, 작은 글자색으로는 안 씀 — 대비 계산으로 확인) |

다섯 시안 모두 서로 다른 답을 냈으므로 "색상만 바꾼 동일 테마"가 아니다. A·B·C는 비대칭,
D는 대칭, E는 "실제 물리적 공간(어두운 상영관+스크린)을 재현"하는 유일한 시안이다 —
나머지 넷이 전부 그래픽적/은유적 장치였던 것과 다르다.

## A — Moving Image Archive

**콘셉트**: 영상 아카이브·독립영화제 프로그램 북. 흰 배경, 검은 타이포, 코발트 블루는
링크·강조 단어에만. 카드 없이 세 작품을 세로 인덱스를 낀 "편집 지면"으로 이어붙였다.
각 지면은 좌우 반전, 화면비 막대그래프 등 서로 다른 내부 그리드를 쓴다.

- 390 / 768 / 1440: `design/design-lab/a/home-{390,768,1440}.png`
- **핵심 컴포넌트**: 스프레드 헤드라인(`justify-between` 단어 분리, 768px 이상에서만),
  세로 `SCREENING INDEX` 라벨, 3종 서로 다른 `<li>` 그리드(좌측대형/우측대형/막대그래프),
  탭 형태 숫자(`tabular-nums`) 스펙 컬럼.
- **장점**: 정보 밀도와 예술성의 균형이 가장 좋음. 영화 스펙(화면비·포맷)이 많아도 잡지
  레이아웃 문법 안에서 자연스럽게 늘어난다. 접근성 위험이 가장 낮음(고대비 흑백 기반).
- **위험 요소**: 자칫 "그냥 흑백 텍스트 사이트"로 밋밋해 보일 수 있어 타이포 스케일·간격
  운용의 정교함에 품질이 크게 좌우된다. 흰 배경이라 브랜드의 "시네마틱함"이 B보다 약하게
  느껴질 수 있음.
- **실제 연결 난이도**: 낮음. 카드가 아닌 리스트 구조라 실제 영화 배열(N개)에도 그대로
  확장 가능 — `<ol>` map만 유지하면 됨. 다만 "지면마다 다른 그리드"를 실제 N개 영화에도
  일관되게 적용할 규칙(예: 3의 배수로 그리드 3종을 순환)이 별도로 필요.

## B — Cinematic Collage

**콘셉트**: 극장의 어둠과 스크린 빛, 화면비 데이터를 하나의 콜라주로 겹친다. 색 섹션
전환 없이 처음부터 끝까지 하나의 다크 캔버스가 이어지고, 세 작품은 각자의 실제 화면비로
빚어진 서로 다른 모양(레터박스 스트립·중앙 플래시·크롭 슬리버)의 패널로 존재한다.

- 390 / 768 / 1440: `design/design-lab/b/home-{390,768,1440}.png`
- **핵심 컴포넌트**: 사선 스크린 라이트 그러데이션, 겹치는 절대배치 타이포, 반투명
  프리뷰 판(테두리 카드 아님), 실제 화면비 기반 3종 콜라주 패널, 화면비 고스트 숫자.
- **장점**: 세 시안 중 시각적으로 가장 강렬하고 기억에 남음 — 브랜드 세계관이 3초 안에
  가장 분명하게 전달된다. "장식이 아니라 실제 화면비가 곧 구성"이라는 원칙이 가장 선명하게
  드러난 시안.
- **위험 요소**: 절대배치 콜라주라 반응형·회귀에 가장 취약(이번 라운드에서도 히어로가
  콘텐츠보다 훨씬 큰 `min-h`를 줘서 캡처에 빈 암전 구간이 생기는 실제 버그가 났고, 고정폭
  버튼 색상도 대비 미달이 처음 나왔다 — 둘 다 발견 즉시 수정). 콘텐츠(영화 수·텍스트 길이)가
  달라지면 겹침 배치를 매번 손으로 재조정해야 할 가능성이 높다.
- **실제 연결 난이도**: 가장 높음. 절대배치 좌표가 "영화 3편"에 맞춰 하드코딩돼 있어
  실제 가변 개수 데이터에 맞추려면 패널 배치 로직 자체를 다시 설계해야 함(예: N개일 때
  콜라주를 어떻게 접을지에 대한 규칙 필요).

## C — Curator's Desk

**콘셉트**: 큐레이터가 관람 조건을 분석해 주는 느낌. 웜페이퍼 배경 + 적색 에디팅 마크
하나. Hero에 비주얼 오브젝트가 아예 없고, 문장 자체가 인터페이스다(밑줄 친 단어가 곧
CTA). 세 작품은 카드가 아니라 번호 붙은 큐레이터 메모로, 각각 "왜 이 영화에서 상영관
선택이 중요한지"를 한 문장으로 붙였다.

- 390 / 768 / 1440: `design/design-lab/c/home-{390,768,1440}.png`
- **핵심 컴포넌트**: 손글씨 SVG 밑줄, 각주(`*`) 스타일 서비스 문구, 인라인 밑줄 CTA,
  점선 밑줄 스펙 태그, 체크마크 SVG가 있는 단일 노트카드(편집 기준+신뢰도 통합), 소량의
  영문 세리프(Lora)로 메타 레이블만 차별화.
- **장점**: 셋 중 가장 지적이고 브랜드 확장성이 높음 — "텍스트가 인터페이스"라는 아이디어가
  다른 화면(검색·출처·제보)까지 자연스럽게 이어질 잠재력이 큼. 접근성 위험도 낮음(A와
  비슷한 고대비 기반, 색은 밑줄·체크마크 등 최소 영역에만).
- **위험 요소**: 비주얼 임팩트가 A·B보다 약해서 "브랜드 인상이 첫 3초에 남는가"라는 기준
  에서는 셋 중 가장 약할 수 있다. 밑줄·각주 같은 인쇄 은유가 실제 서비스에서 "링크처럼
  안 보인다"는 사용성 피드백을 받을 가능성이 있다.
- **실제 연결 난이도**: 낮음~중간. 메모 리스트 구조는 A처럼 확장이 쉽지만, 영화별 "선택이
  중요한 이유" 한 문장은 실제 데이터로 자동 생성하기 어려운 편집 카피라서, 실제 서비스에
  붙이려면 이 문장을 어떻게 만들지(수동 큐레이션 vs 규칙 기반 생성) 별도 결정이 필요하다.

## D — Grand Foyer

**콘셉트**: "세련되고 단단한 멋쟁이 극장" 피드백에 대한 답. 웜 차콜(다크) + 웜 크림
(라이트) + 크림슨 액센트 하나. 좌우 대칭·중앙 정렬 구조로 A·B·C의 비대칭 긴장 대신
"중심 잡힌 균형"에서 단단함을 낸다. Hero는 극장 마퀴(간판) 사인보드처럼 크림슨 이중
룰로 감싼 중앙 정렬 문장이고, 영화 세 편은 카드가 아니라 하나의 사인보드 프레임 안에
3행으로 들어가 있다(첫 행만 확대해 위계를 주되 여전히 하나의 오브젝트). 다크→라이트→
다크로 정확히 한 번만 전환해(반복 아님) 밝은 로비 대비를 내고, 그 앞뒤를 크림슨 버튼이
같은 리듬으로 bookend한다 — "아늑하되 널찍함"은 이 넉넉한 여백과 중앙 정렬 대칭에서.

- 390 / 768 / 1440: `design/design-lab/d/home-{390,768,1440}.png`
- **핵심 컴포넌트**: 중앙 정렬 마스트헤드, 크림슨 이중 룰 히어로 프레임, 단일 사인보드
  프레임 안 3행(위계는 크기 차이로만), 크림슨 구분 눈금(`DividerTick`), 다크→라이트→
  다크 대칭 bookend.
- **장점**: 넷 중 가장 "브랜드 있는 고급 상업 공간" 같은 인상 — 실제 극장 로비에 온
  듯한 물리적 공간감이 가장 강하다. 대칭 구조라 실제 콘텐츠 길이가 들쭉날쭉해도 무너질
  위험이 A·B보다 낮다(정렬 기준이 항상 중앙 하나).
  자체 검증 중 실제로 잡은 버그(정직하게 기록): 헤더 워드마크와 영화 제목이 각각 처음엔
  전역 CSS의 기본 링크색(파란색)을 그대로 물려받아 시안의 팔레트(웜톤+크림슨)와 무관한
  파란 텍스트로 렌더링되고 있었다 — 링크에 명시적 텍스트 색을 지정하지 않은 실수였고,
  axe는 후자를 잡지 못했지만(그 위치에서는 대비 자체는 통과) 시안의 색 언어와 완전히
  어긋나는 요소라 스크린샷으로 직접 발견해 수정했다. 그 외 사인보드 안 스펙 텍스트 하나가
  대비 4.4:1로 기준(4.5:1) 미달이었던 것도 axe가 잡아 수정했다.
- **위험 요소**: 대칭·정적 구성이라 A·B·C보다 "실험적"이라는 인상은 약할 수 있다(더
  안전해 보임 = 더 예측 가능해 보임의 트레이드오프). 크림슨 하나만 쓰는 절제가 무너지면
  "그냥 빨간 버튼 있는 흔한 브랜드"로 보일 위험 — 룰·구분 눈금 등 크림슨을 "선"으로만
  쓰는 절제를 실제 반영 단계에서도 지켜야 한다.
- **실제 연결 난이도**: 낮음. 사인보드는 실제로 `LAB_MOVIES.map` 하나로 구현돼 있어
  영화 개수가 변해도 그대로 확장된다(첫 행만 확대하는 위계 규칙도 인덱스 0 조건 하나뿐).
  네 시안 중 실제 서비스 데이터에 가장 손쉽게 연결된다.

## E — The Screening Room

**콘셉트**: "영화 극장 스크린 생각나게, CGV 느낌" 피드백에 대한 답. A~D가 전부 은유적/
그래픽적 장치였던 것과 달리, E는 은유 없이 "어두운 상영관에 앉아 빛나는 스크린을 본다"는
장면 하나를 그대로 그린다. 문구는 스크린 위가 아니라 객석(다크 전경)에 두고, 스크린은
순수한 빛의 오브젝트로만 남긴다(스크린 위에 텍스트를 얹지 않은 이유는 아래 버그 기록

실제 멀티플렉스의 언어로 문 3개가 있고, 문틈으로 새어 나오는 빛의 양(86% / 60% / 34%)이
각 작품의 성격(듄의 개방감, 오펜하이머의 강한 빛, 존 오브 인터레스트의 절제)을 그대로
반영한다.

- 390 / 768 / 1440: `design/design-lab/e/home-{390,768,1440}.png`
- **핵심 컴포넌트**: 커튼 주름 텍스처(반복 그러데이션), 순수 빛 오브젝트 스크린(텍스트
  없음), 좌석 실루엣(`SeatRow`), 개방 정도가 서로 다른 "상영관 문" 3개, 복도 조명처럼
  쓰는 작은 점(criteria 구분자, D의 크림슨 눈금과는 다른 은유).
- **장점**: 다섯 시안 중 "실제 물리적 공간에 있다"는 감각이 가장 강하다 — 브랜드
  세계관이 아니라 실제 극장 방문 경험을 재현해서, 첫인상의 "이건 영화 서비스다"라는
  전달력이 가장 직접적이다. CGV 같은 실제 멀티플렉스의 언어(1관/2관/3관)를 써서 친숙함도
  높다.
- **자체 검증 중 실제로 잡은 버그(정직하게 기록)**: 캡처 스크립트 자체의 결함을 여기서
  처음 발견했다 — 이전까지 쓰던 "맨 위→맨 아래로 한 번에 스크롤"하는 캡처 방식은 문서
  높이가 뷰포트의 2배를 넘으면 중간 구간이 단 한 번도 뷰포트에 걸치지 않아 그 구간의
  scroll-reveal이 영원히 `opacity:0`로 남는다는 사실을, E의 390px 캡처(1관·2관 전체가
  빈 화면으로 찍힘, 문서 높이가 뷰포트의 3배 이상)로 실제로 발견했다. 뷰포트 높이 단위로
  전체를 훑는 방식으로 캡처 스크립트를 고치고, A~D도 같은 방식으로 재검증해 이상 없음을
  확인했다(우연히 A~D의 문서 높이가 뷰포트의 2배를 넘지 않아 그동안은 드러나지 않았을

  하드코딩했다 — 실제 서비스에서는 이 값을 매치 점수나 추천 순위 같은 실데이터에 연결할

## 종합

다섯 시안 모두 §1의 금지 목록(좌우 분리 Hero, 카드 3개, 01~04 리스트, 신뢰도 불릿+CTA,
겹친 화면비 사각형 Hero, 현재 MATCH 96% 카드, dark→light 반복)을 다시 쓰지 않았고, 서로
다른 배경 리듬·카드 개수·타이포 전략·핵심 컴포넌트를 갖는다(위 비교표 참고). A·B·C는
비대칭, D는 대칭, E는 은유 대신 실제 공간 재현 — 다섯이 서로 겹치지 않는 구성 원리를 쓴다.

접근성은 다섯 시안 모두 axe(WCAG 2.2 AA) 기준 위반 0건으로 확인했다(390/768/1440 각각,
D·E는 발견된 위반을 수정한 뒤 재검증까지 통과). production 홈(`/`)과 그 외 기존 라우트는
헤더를 공통 컴포넌트로 옮긴 것 외에 아무것도 바꾸지 않았고, 기존 e2e 스위트 74개(시각
회귀 포함) 전부 변경 없이 통과해 무영향을 확인했다.
