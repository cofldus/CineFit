# 베타 기간 개인정보 처리 안내 (초안)

- 기준일: 2026-07-28 (7차 마일스톤)
- **법률 자문이 아니다.** 실제 공개 베타를 시작하기 전 이 문서를 법률 검토를 거쳐 정식
  개인정보 처리방침으로 대체해야 한다. 지금은 "지금 코드가 실제로 수집·저장하는 것"을
  있는 그대로 설명한다(`docs/DATA-RETENTION.md`의 기술적 근거와 짝을 이룬다).

## CineFit이 수집하는 것

- **익명 세션 id**: 로그인 없이 브라우저에 저장되는 회전 가능한 임의 문자열(쿠키
  `cinefit_session`). 이 id와 실명·이메일·전화번호를 연결하는 어떤 테이블도 없다.
- **사용 이벤트**: 어떤 화면을 봤는지, 어떤 조건으로 추천을 요청했는지, 추천에 만족했는지
  등(`docs/ANALYTICS.md`의 16개 이벤트 목록 전체).
- **추천 피드백·선택·관람 후 평가**: 익명 세션 id와만 연결된다.
- **제보 시 선택적 이메일**: 상영관 정보 제보 폼에서 연락처 이메일을 남길 수 있으나
  **선택 사항**이며, 관리자 검토 화면에만 표시되고 공개 화면에는 절대 노출되지 않는다.

## CineFit이 수집하지 않는 것

- 정확한 GPS 좌표(출발 위치는 6개 지역 프리셋 중 선택만 가능).
- 전체 IP 주소, 기기 광고 식별자.
- 자유 입력 텍스트 전문(피드백은 정해진 이유 코드 체크박스만 저장하고, 자유 텍스트 필드가
  있는 곳도 이벤트 속성으로는 절대 넘어가지 않는다 — 스키마가 알 수 없는 속성을
  자동으로 걸러낸다, `docs/ANALYTICS.md`).
- 결제·신용카드 정보(예매는 항상 각 극장 공식 예매 페이지로 이동해 처리한다 — CineFit은
  결제를 다루지 않는다).
